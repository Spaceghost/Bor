# Borr

An Odin-to-C compiler, written in Odin. Repository and executable: `Bor` / `bor`.

The first milestone is a checked, executable language slice with deterministic C output and a differential shootout. The direction is a compact, inspectable, data-oriented compiler: explicit semantics before optimization, reproducible evidence before performance claims.

Implementation and executable tests are being established. This is not yet a complete Odin implementation or a self-hosting compiler.
